# Instrument market survey — 2026-10-15

Initial manufacturer-sourced inventory, **not an exhaustive census or current-availability claim**. Includes historical instruments and some adjacent displays to be classified during review.

## Workflow
1. Verify model identities, variants and manufacturer documentation.
2. Register manual title, revision, URL, retrieval date and checksum where available.
3. Extract display, power, ingress protection, interface, firmware and sensor specifications with page references.
4. Review uncertainty, product lifecycle and comparison class.
5. Design repeatable tests before publishing any comparative performance claims.

## Files
- `instrument-display-inventory.csv` — product research candidates.
- `official-source-seed.csv` — official primary-source links awaiting manual and revision verification.
