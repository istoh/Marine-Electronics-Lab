# AI Agent Instructions

## Purpose
Support independent marine electronics research, documentation analysis, test planning and evidence-based comparisons.

## Mandatory rules
1. Identify the original source of every technical assertion.
2. Record document title, publisher, version, URL, retrieval date and page/section.
3. Never invent missing specifications, compliance claims or measurements.
4. Separate manufacturer claims, independently verified facts, measured results and hypotheses.
5. Maintain traceability between sources, extracted requirements, test cases and results.
6. Prefer primary manufacturer documentation and official standards.
7. Flag contradictory revisions and uncertainties for human review.
8. Never claim a test was performed without recorded evidence.
9. Keep the research project independent of other product-development projects.
10. Respect copyright, licensing, confidentiality and redistribution restrictions.

## Research workflow
Source discovery → Registration → Analysis → Feature extraction → Test design → Human review → Measurement → Analysis → Publication.

## Test case schema
Each test includes a unique ID, product and firmware version, source reference, objective, required equipment, environment, procedure, expected behavior or acceptance criteria, measurement uncertainty where applicable, actual results, evidence and status.

## Quality assurance
AI-generated technical conclusions require source verification. Mark unverified conclusions clearly. Preserve raw measurement records and document corrections separately. Distinguish manufacturer specifications, standards requirements and editorial comparison criteria.
